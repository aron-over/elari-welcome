Eenmalig koppelen met GitHub

  1. Open github.com/settings/personal-access-tokens/new.
  2. Naam: elari welcome. Verloopt: 1 jaar.
  3. Bij "Repository access" kies Only select repositories en kies elari-welcome.
  4. Bij "Permissions", "Repository permissions", zet Contents op Read and write.
  5. Klik Generate token, kopieer de code en plak hem hieronder.

De code blijft alleen in de browser op deze pc bewaard.
